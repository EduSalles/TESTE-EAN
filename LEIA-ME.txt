PESQUISA DE PREÇOS — SINCRONIZAÇÃO DO CADASTRO PELO GITHUB PAGES

Arquivos:
- index.html: aplicativo
- produtos.json: cadastro central exportado do ConnectPlug (15/10/2026)

PUBLICAÇÃO
1. No repositório GitHub que hospedará o aplicativo, envie/substitua index.html e adicione produtos.json na mesma pasta.
2. Ative GitHub Pages nas configurações do repositório (se ainda não estiver ativo).
3. Abra o endereço HTTPS do GitHub Pages nos dois celulares.

SINCRONIZAÇÃO
- Ao abrir o aplicativo, ele consulta ./produtos.json e pergunta antes de carregar uma nova versão.
- O cadastro e as coletas continuam salvos localmente em cada celular.
- Atualizar produtos.json no GitHub disponibiliza o novo cadastro para os dois aparelhos.
- Os preços coletados/pesquisas não são sincronizados entre celulares; apenas o cadastro mestre.
- Não abra index.html diretamente como arquivo local: nesse modo o navegador bloqueia a consulta confiável do arquivo central.

IMPORTANTE
O código usa uma URL relativa (./produtos.json), portanto os dois arquivos devem ficar na mesma pasta publicada pelo GitHub Pages.
